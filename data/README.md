# Data

Primary dataset: **RiceLeafDiseaseBD Version 2**.
DOI: 10.17632/86s4jzj2m4.2

The study used the original-image classification folders, not the object-detection annotations. The original 9,769 images were audited using exact-content hashing. The cleaned dataset contained 9,722 unique images.

Clean split:
- Training: 7,777
- Validation: 972
- Locked held-out test: 973

The dataset itself is not included in this repository.
